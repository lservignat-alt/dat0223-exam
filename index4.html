Minimum Spanning Trees & Kruskal 10 pts

This exercise covers the theory of Minimum Spanning Trees and Kruskal's algorithm. Write your answers directly in the text fields below. No automated tests — your answers will be graded manually.

Theory
Q1 — Definition & properties of an MST (2 pts)

a) Give a formal definition of a Minimum Spanning Tree of a graph G = (V, E) with weight function w: E → ℝ.

b) State two fundamental properties that every MST must satisfy. Justify why removing any edge from an MST disconnects the tree.

c) Is the MST of a graph always unique? Under what condition is it guaranteed to be unique? Give a counterexample if not.

Q2 — Trace Kruskal's algorithm on G (3 pts)

Apply Kruskal's algorithm step by step on the graph G defined above.

  1. Sort all edges by weight (ascending) and list them in order.
  2. For each edge, state whether it is added or rejected (cycle), and why.
  3. Give the final MST as a list of edges and compute its total weight.
Q3 — Union-Find: structure & role (3 pts)

a) Describe the Union-Find data structure. What does each operation (find, union) do, and what is their time complexity with path compression and union by rank?

b) Explain precisely how Union-Find is used in Kruskal's algorithm to detect cycles. What does it mean for two nodes to be in the same component?

c) Without Union-Find, what alternative method could you use to detect cycles, and what would be the impact on the overall time complexity of Kruskal's algorithm?

Q4 — Time complexity analysis (2 pts)

a) Give the full time complexity of Kruskal's algorithm and break it down by step: sorting edges, and processing edges with Union-Find. Justify each term using |V| and |E|.

b) Compare with Prim's algorithm: which is more efficient on dense graphs (|E| ≈ |V|²)? On sparse graphs (|E| ≈ |V|)? Justify your answer.

Random Walks & PageRank 15 pts

PageRank models the importance of nodes in a directed graph using random walks with a damping factor. You will implement it from scratch using power iteration.

Questions
Q1 — Build the transition matrix (4 pts)

Implement transition_matrix(G) where G is an adjacency dict of directed edges.

  1. The matrix must be row-stochastic: each row sums to 1 (probability of following each outgoing link).
  2. Handle dangling nodes (nodes with no outgoing edges): distribute their probability uniformly across all nodes.
  3. Return the matrix as a 2D list of floats and print it formatted with 4 decimal places.
Q2 — Power iteration for PageRank (5 pts)

Implement pagerank(G, d=0.85, iterations=100) using the formula:

PR(u) = (1-d)/N + d × Σ PR(v)/out_degree(v) for all v→u

  1. Initialize all ranks to 1/N.
  2. At each iteration, apply the formula above for all nodes simultaneously (use a copy of ranks).
  3. After 100 iterations, return the final ranks as a dict.
Q3 — Analyse the results (3 pts)

Print PageRank scores sorted from highest to lowest. Then add a comment block answering:

  1. Which page has the highest PageRank, and why does it make structural sense given the graph topology?
  2. What happens to all PageRank scores if you set d=0? And if d=1? Explain the mathematical reason.
Q4 — Convergence & stationary distribution (3 pts)

Modify your code to track convergence: at each iteration, compute the L1 norm of the change in rank vector. Stop early when this norm is below 1e-6 and print how many iterations were needed.

In a comment, explain the link between PageRank and the stationary distribution of a Markov chain. Under what conditions is the stationary distribution unique?
